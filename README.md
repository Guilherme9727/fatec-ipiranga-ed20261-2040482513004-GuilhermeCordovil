## ⭐ Projeto em destaque — Editor de Texto com Undo/Redo

Um dos projetos desenvolvidos na disciplina implementa um pequeno **editor de texto em C** com funcionalidades de **desfazer (Undo)** e **refazer (Redo)**.

O projeto utiliza **pilhas dinâmicas** para armazenar os estados do texto e controlar o histórico das operações.

### Conceitos aplicados

- estruturas do tipo pilha (*stack*);
- nós encadeados;
- ponteiros;
- alocação dinâmica com `malloc`;
- liberação de memória com `free`;
- manipulação de strings;
- operações `push` e `pop`;
- histórico de estados;
- lógica de Undo/Redo.

### Funcionamento

```text
Texto atual
    ↓
alteração
    ↓
salva estado anterior
    ↓
pilha de histórico
    ↕
Undo / Redo
```
