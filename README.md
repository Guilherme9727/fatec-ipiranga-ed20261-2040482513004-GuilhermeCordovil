## Objetivo

Registrar a prática de conceitos fundamentais de estrutura de dados e resolução de problemas computacionais ao longo da disciplina.

## Competências desenvolvidas

- raciocínio algorítmico;
- decomposição de problemas;
- implementação de estruturas de dados;
- análise do comportamento de algoritmos;
- organização de código;
- versionamento com Git e GitHub.
