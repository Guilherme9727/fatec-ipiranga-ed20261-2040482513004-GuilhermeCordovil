### 📖 Sobre o Projeto

Sistemas de edição de texto precisam de mecanismos seguros para que o usuário tenha controle sobre o que digita. O principal deles é a funcionalidade de **desfazer (undo)** que permite reverter erros ou operações acidentais.

O objetivo deste projeto é construir esse mecanismo na linguagem **C (ANSI/ISO)**. Para garantir a rastreabilidade e a ordem correta das ações (como inserções e remoções de caracteres), utilizamos o conceito de **Pilhas (Stacks)** para gerenciar a memória do texto.

### ⚙️ O que o código faz
* Permite inserir e remover caracteres.
* **Undo:** Desfaz a última alteração feita no texto.
